# Command-Line To-Do App 📝

A simple, lightweight command-line task manager built with Python. This project allows users to add, view, complete, and delete tasks with persistent data storage using JSON.

## Features
- **Add Tasks:** Create new tasks with custom descriptions.
- **View Tasks:** Check your active and completed items.
- **Mark Complete:** Update task status with an indicator (`✓`).
- **Data Persistence:** Automatically saves tasks to a local JSON file so nothing is lost when the program closes.
